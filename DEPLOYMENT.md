# Deployment status

No public deployment has been attempted. The existing development Dockerfiles/Compose are preserved. Separate [release configuration](infrastructure/production/README.md) now uses PHP-FPM/OPcache, Next.js standalone, a TLS Nginx gateway, private media volume, supervised database queue and Reverb. The isolated CI stack built and ran successfully: [verified run](https://github.com/mhmdhabibrafi/simeyo/actions/runs/38689026253). This machine still has no Docker Engine; its development Redis/MinIO/Meilisearch stack remains unverified.

A production deployment still needs real hostname/certificates, approved database credentials and permissions, SMTP, resource/monitoring settings, production media/key recovery, rollback acceptance and sustained staging load. The CI test verifies TLS, health, login/logout, CSRF, Secure/HttpOnly cookies, private headers, feed access and realtime configuration; it does not prove private WebSocket delivery through the gateway or external provider operations. PostgreSQL backup/restore was exercised separately in disposable CI databases; see [recovery procedure](docs/operations/backup-restore.md).

Do not seed demo accounts in production. Do not run destructive reset commands on existing data. The owner authorized Git source publication to mhmdhabibrafi/simeyo. Public application deployment, force-push and infrastructure deletion remain outside the authorized scope.
