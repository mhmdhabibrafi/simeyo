# Contributing

Preserve existing local changes and data. Use strict TypeScript, small module-specific Laravel controllers/actions, policy authorization and database constraints. Run API tests, appropriate browser/security checks, lint, typecheck and build before marking a milestone complete. Use Pint for PHP and Prettier for web source.

Update OpenAPI/contracts when endpoints change, and maintain PROGRESS.md with actual results. Label untested work BELUM DIUJI. Never assign a release version because files were created, suppress failing tests, hardcode secrets/demo credentials, or confuse build success with UI/persistence/deployment verification.
