# Simeyo web

Next.js App Router identity foundation, v0.1.0. See the root [README](../../README.md) and [PROGRESS](../../PROGRESS.md) for actual functionality, setup and verification.

Run from this directory: `npm run dev`, `npm run build`, `npm run lint`, `npm run typecheck`, `npm run test:e2e`. Laravel/PostgreSQL must be running for authenticated routes and browser tests.
