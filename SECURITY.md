# Security status

Implemented and API-tested: password hashing/validation, session rotation/logout, recovery token validation, session/token revocation, native token expiry/scope, rate limiting, email-owner/hash/signature/expiry, membership gating, institution-scoped review, denial of self-review and privilege mass assignment, academic visibility, safe profile URLs, media type/dimension/size validation and metadata-free encoding. Browser testing covers CSRF rejection and persisted cookie login.

Profile text renders as React text; no raw HTML rendering. Profile links accept only HTTP/HTTPS and external links use noopener. Images stay private; Next Image uses `unoptimized` because the image optimizer cannot carry the viewer's session cookie and must not create a shared cache of private images. Media responses are private/no-store. Native credentials use device-only SecureStore; account changes clear caches. Physical-device secure-storage acceptance remains pending.

No institutional credentials, real student records, document uploads or production secrets are embedded. `.env`, `.local`, runtime databases, tokens and logs are ignored. Test artifacts may include short-lived signed URLs/session cookies; Playwright traces and HTML reports are ignored and must not be publicly published. Fictional screenshots may be retained as evidence.

Manual verification is an operator-reviewed **statement**, not cryptographic proof of affiliation. Operators must define an independent verification procedure before opening to real campus users. Self-claimed faculty/department choices are contextual metadata, not role grants.

Production release acceptance remains gated. Isolated CI verified PostgreSQL/application recovery and the HTTPS Nginx/PHP-FPM/standalone web stack, private WSS and worker failure/recovery. Synthetic 120-second read load passed 960 requests with zero errors and endpoint p95 113–328 ms; campus capacity and long soak remain unverified. Optional Redis/S3-compatible/search services passed isolated checks. Fresh release-image scanning found zero HIGH/CRITICAL findings in its recorded scope; five web and 18 mobile development-tooling npm advisory entries remain open. Do not use forced framework downgrades or infer a clean full dependency graph. Production SMTP, full threat review, account retention/deletion, off-host recovery, external alerting and physical-device/push acceptance remain outstanding. See PROGRESS.md for current deployment and test evidence.
